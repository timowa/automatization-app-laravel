# Wall API Methods

Документация методов раздела Wall VK API.
Используются в: CreateVkPostJob, CreateVkRepostJob, CreateVkCommentJob.

Источник: https://dev.vk.com/ru/method/wall

---

## wall.post

Метод позволяет:
- Создать запись на стене.
- Предложить запись на стене публичной страницы.
- Опубликовать существующую отложенную запись.

Метод не используется в играх и мини-приложениях.

### Ограничения на публикуемый контент

- В посте обязательно должен быть один из типов контента: текст, фото, видео, сниппет ссылки или статья.
- В пост можно добавить не более 10 медиа (фото, видео).

**Аудио**
- В пост можно добавить до 10 музыкальных треков или 1 плейлист/альбом/подкаст.
- Добавлять треки, альбомы, плейлисты или подкасты можно только с фото и видео в режиме карусели.
- В режиме отображения сетка аудио добавлять нельзя.

**Опросы**
- Можно добавить только 1 опрос.
- Опрос не может быть единственным вложением — нужен текст, фото или видео.
- Длина ответов в опросе — до 100 символов.

**Файлы**
- К посту можно прикрепить один файл.
- Требования к gif-файлам: соотношение сторон от 0,66:1 до 2,5:1.
- Требования к картинкам для сниппета статьи: соотношение сторон от 1:1 до 1:2, минимальная ширина 550 пикселей.
- Требования к картинкам для сниппета ссылки: соотношение сторон от 1:1 до 1:2,5, минимальная ширина 500 пикселей.
- Если передать ссылку без изображения, сниппет не сформируется. Чтобы получить изображение, используйте метод wall.parseAttachedLink.

### Ключи доступа

Для вызова метода можно использовать:
- ключ доступа пользователя, полученный в Standalone-приложении через Implicit Flow (требуется право доступа: wall — выдаётся в исключительных случаях через запрос в поддержку по электронной почте devsupport@corp.vk.com)

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `owner_id` | integer | Идентификатор пользователя или сообщества, на стене которого необходимо опубликовать запись. Идентификатор сообщества должен начинаться со знака `-`. |
| `friends_only` | checkbox | 1 — запись доступна только друзьям. 0 — запись доступна всем пользователям. Значение по умолчанию. |
| `from_group` | checkbox | Учитывается, если owner_id меньше 0. 1 — от имени сообщества. 0 — от имени пользователя (по умолчанию). |
| `message` | text | Текст сообщения. Обязательный параметр, если не задан параметр attachments. |
| `attachments` | string | Объект или несколько объектов, приложенных к записи. Обязательный параметр, если не задан параметр message. |
| `photo_attachments_crop` | text | Параметр обрезки для фото. Массив объектов JSON. |
| `primary_attachments_mode` | string | Формат отображения прикреплённых медиа файлов: карусель (по умолчанию) или grid (сетка). |
| `services` | string | Список сервисов или сайтов, на которые необходимо экспортировать запись. |
| `signed` | checkbox | 1 — добавить подпись (имя пользователя). 0 — не добавлять (по умолчанию). |
| `publish_date` | positive | Дата и время публикации записи (Unix Timestamp). Публикация будет отложена. |
| `lat` | string | Географическая широта в градусах. От -90 до 90. |
| `long` | string | Географическая долгота в градусах. От -180 до 180. |
| `place_id` | positive | Идентификатор местоположения. |
| `post_id` | positive | Идентификатор записи для публикации отложенных записей и предложенных новостей. |
| `guid` | string | Уникальный идентификатор для предотвращения повторной отправки. Действует в течение одного часа. |
| `mark_as_ads` | checkbox | 1 — добавить отметку «Это реклама». 0 — не добавлять (по умолчанию). |
| `link_title` | string | Заголовок сниппета для прикрепленного объекта. |
| `link_photo_id` | string | Идентификатор видео или фотографии в формате {owner-id}_{photo-id}. |
| `close_comments` | checkbox | 1 — комментарии отключены. 0 — включены (по умолчанию). |
| `donut_paid_duration` | integer | Период доступности только для донов: -1, 86400 (1 день), 172800 (2 дня), 259200 (3 дня), 345600 (4 дня), 432000 (5 дней), 518400 (6 дней), 604800 (7 дней). |
| `mute_notifications` | checkbox | 1 — уведомления отключены. 0 — включены. |

При публикации отложенной записи все параметры, кроме owner_id и post_id, игнорируются.

#### Формат attachments

Формат описания медиавложения: `{type}{owner_id}_{media_id}`

- `type` — тип: photo, video, audio, doc, poll, audio_playlist
- `owner_id` — идентификатор владельца (сообщества со знаком `-`)
- `media_id` — идентификатор медиавложения

Формат описания ссылки: `{protocol}://{URL}`

Можно указать несколько медиавложений, но только одну ссылку.

### Результат

Метод возвращает объект:

| Поле | Тип | Описание |
|------|-----|----------|
| `post_id` | integer | Идентификатор записи. |

### Пример ответа

```json
{
  "response": {
    "post_id": 17
  }
}
```

## wall.repost

Метод позволяет сделать репост — скопировать запись на стену пользователя или сообщества.

### Ключи доступа

- ключ доступа пользователя, полученный в Standalone-приложении через Implicit Flow (требуется право доступа: wall)

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `object` | string | Обязательный. Строковый идентификатор объекта, например `wall66748_3675` или `wall-1_340364`. Формируется из типа объекта, идентификатора владельца и идентификатора объекта. |
| `message` | string | Сопроводительный текст. Максимальная длина — 4096 символов. |
| `group_id` | positive | Идентификатор сообщества, на стене которого будет размещена запись. Если не указан — на стене текущего пользователя. |
| `mark_as_ads` | checkbox | 1 — пометить запись как рекламную. |
| `mute_notifications` | checkbox | 1 — уведомления отключены. 0 — включены. |

### Результат

После успешного выполнения возвращает объект:

- `success` — всегда содержит 1
- `post_id` — идентификатор созданной записи
- `reposts_count` — количество репостов объекта с учётом осуществленного
- `likes_count` — число отметок «Нравится» у объекта

### Коды ошибок

| Код | Описание |
|-----|----------|
| 214 | Access to adding post denied |
| 219 | Advertisement post was recently added |
| 224 | Too many ads posts |
| 13000 | Content upload was denied due to active community strikes |

## wall.getById

Возвращает список записей со стен пользователей или сообществ по их идентификаторам.

### Ключи доступа

- ключ доступа пользователя
- сервисный ключ доступа

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `posts` | string | Обязательный. Идентификаторы через запятую: `ID_владельца_ID_записи`. Максимум 100 идентификаторов. Пример: `93388_21539,93388_20904,-1_340364` |
| `extended` | checkbox | 1 — вернуть дополнительные поля profiles и groups. По умолчанию: 0. |
| `copy_history_depth` | integer | Размер массива copy_history, если запись является репостом. |
| `fields` | string | Список дополнительных полей для профилей и групп. Учитывается только при extended=1. |

### Результат

Возвращает объект, содержащий массив объектов записей на стене.
При extended=1 — отдельно: items (записи), profiles (пользователи), groups (сообщества).

### Коды ошибок

| Код | Описание |
|-----|----------|
| 104 | Not found |

## wall.createComment

Добавляет комментарий к записи на стене.

### Ключи доступа

- ключ доступа пользователя, полученный в Standalone-приложении через Implicit Flow (требуется право доступа: wall)
- ключ доступа сообщества

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `owner_id` | integer | Идентификатор пользователя или сообщества. Для сообщества — со знаком `-`. |
| `post_id` | positive | Обязательный. Идентификатор записи на стене. |
| `from_group` | integer | Идентификатор сообщества, от имени которого публикуется комментарий. По умолчанию: 0. |
| `message` | text | Текст комментария. Обязательный, если не передан attachments. |
| `reply_to_comment` | integer | Идентификатор комментария, в ответ на который добавляется новый. |
| `attachments` | string | Список объектов через запятую. Формат: `<type><owner_id>_<media_id>`. |
| `sticker_id` | positive | Идентификатор стикера. |
| `guid` | string | Уникальный идентификатор для предотвращения повторной отправки. |

### Результат

Возвращает идентификатор добавленного комментария в поле `comment_id` (integer) и массив идентификаторов родительских комментариев в поле `parent_stack` (array).

### Коды ошибок

| Код | Описание |
|-----|----------|
| 212 | Access to post comments denied |
| 213 | Access to status replies denied |
| 222 | Hyperlinks are forbidden |
| 223 | Too many replies |
| 13000 | Content upload was denied due to active community strikes |
