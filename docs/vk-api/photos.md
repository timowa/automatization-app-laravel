# Photos API Methods

Документация методов раздела Photos VK API.
Используются в: CreateVkPostJob (загрузка фото для поста), CreateVkProductJob (загрузка фото для товара).

Источник: https://dev.vk.com/ru/method/photos

---

## photos.getWallUploadServer

Метод получает адрес сервера для загрузки фотографии на стену пользователя или сообщества.

### Ключи доступа

- ключ доступа пользователя (требуется право доступа: photos)

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `group_id` | integer | Необязательный. Идентификатор сообщества, на стену которого нужно загрузить фотографии (без знака `-`). |

### Результат

| Поле | Тип | Описание |
|------|-----|----------|
| `album_id` | integer | Идентификатор альбома, в который нужно загрузить фотографии. |
| `upload_url` | string | Адрес, по которому нужно загрузить фотографии. |
| `user_id` | integer | Идентификатор пользователя или сообщества, на стену которого будут загружены фотографии. |

### Пример ответа

```json
{
  "response": {
    "album_id": -14,
    "upload_url": "https://pu.vk.com/c856312/ss2152/upload.php?act=do_add&mid=743784474&aid=-14&gid=0&hash=bd9a7f37b8af6c5e486a3762a4c7b797&rhash=f4c2595ded6f9b3e8954567d4f8eae57&swfupload=1&api=1&wallphoto=1",
    "user_id": 743784474
  }
}
```

### Коды ошибок

В ходе выполнения могут произойти общие ошибки.

## photos.saveWallPhoto

Метод сохраняет фотографии на стене после их успешной загрузки на сервер.

### Ключи доступа

- ключ доступа пользователя

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `user_id` | positive | Необязательный. Идентификатор пользователя, на стену которого необходимо сохранить фотографию. |
| `group_id` | positive | Необязательный. Идентификатор сообщества, на стену которого необходимо сохранить фотографию. |
| `photo` | string | Обязательный. Фотография в формате multipart/form-data. Возвращается в результате загрузки на сервер. |
| `server` | integer | Обязательный. Идентификатор сервера. Возвращается в результате загрузки на сервер. |
| `hash` | string | Обязательный. Хеш фотографий. Возвращается в результате загрузки на сервер. |
| `latitude` | string | Необязательный. Географическая широта. От -90 до 90. |
| `longitude` | string | Необязательный. Географическая долгота. От -180 до 180. |
| `caption` | string | Необязательный. Текст описания фотографии. Макс. 2048 символов. |

### Результат

Метод возвращает массив объектов фотографий.

Каждый объект содержит поля: `album_id`, `date`, `id`, `owner_id`, `access_key`, `sizes` (массив размеров с полями height, type, width, url), `text`, `has_tags`.

| Код | Описание |
|-----|----------|
| 22 | Upload error |
| 114 | Invalid album id |

## photos.getMarketUploadServer (устаревший)

> **Внимание:** Метод удалён из актуальной документации VK API (возвращает 404 на dev.vk.com).
> В проекте vk19-app метод всё ещё вызывается через VK PHP SDK в `VkApiService::createProduct()`.
>
> Аналог в актуальной документации: `photos.getMarketAlbumUploadServer` — получает адрес сервера
> для загрузки фотографии подборки товаров (а не самого товара).
>
> Параметры, использовавшиеся в проекте:
> - `group_id` (integer) — идентификатор сообщества
> - `main_photo` (1) — загрузка как главной фотографии товара
>
> Источник: https://dev.vk.com/ru/method/photos.getMarketUploadServer (недоступно)

## photos.saveMarketPhoto (устаревший)

> **Внимание:** Метод удалён из актуальной документации VK API (возвращает 404 на dev.vk.com).
> В проекте vk19-app метод всё ещё вызывается через VK PHP SDK в `VkApiService::createProduct()`.
>
> Аналог в актуальной документации: `photos.saveMarketAlbumPhoto` — сохраняет фотографию
> подборки товаров сообщества (а не самого товара).
>
> Параметры, использовавшиеся в проекте:
> - `group_id` (integer) — идентификатор сообщества
> - `photo` (string) — фотография в формате multipart/form-data
> - `server` (integer) — идентификатор сервера
> - `hash` (string) — хеш
> - `crop_data` (string) — данные обрезки
> - `crop_hash` (string) — хеш обрезки
>
> Источник: https://dev.vk.com/ru/method/photos.saveMarketPhoto (недоступно)
